# food-store-parcial
Primer parcial Programación III - Food Store con carrito, búsqueda y filtros

## Descripción
Aplicación frontend de tienda de alimentos que permite:
- Ver catálogo de productos
- Buscar productos por nombre
- Filtrar por categoría
- Agregar productos al carrito con persistencia en localStorage
- Ver carrito con cantidades y total

## Tecnologías
- HTML5, CSS3
- TypeScript, JavaScript
- Vite como bundler
- localStorage para persistencia

# Instalar dependencias
pnpm install

# Levantar servidor de desarrollo
pnpm dev
